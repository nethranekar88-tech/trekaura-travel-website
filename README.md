# TrekAura – Weekend Treks & Travel Website

A modern and responsive travel website built using HTML, CSS, and JavaScript. TrekAura is designed for trekking groups, travel planners, and weekend getaway brands to showcase trips, attract users, and generate enquiries.

The project features a premium green travel theme, interactive trip detail popups, traveller reviews, FAQ section, and a clean responsive layout suitable for portfolios, clients, and freelance demonstrations.

---

## ✨ Features

* Responsive design for desktop, tablet, and mobile
* Premium green & earthy travel-themed UI
* Sticky navigation bar
* Hero section with trekking image and call-to-action buttons
* Featured trip cards with price, duration, and difficulty
* Interactive “View Details” popup modal for every trip
* Traveller reviews section
* FAQ section
* Final CTA section with “Plan Your Trip”
* Easy to customize for trekking groups, travel pages, and tour organizers

---

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/nethranekar88-tech/trekaura-travel-website.git
```

Open the project folder and run:

* Double click `index.html`

OR

* Open in VS Code
* Install Live Server extension
* Right click `index.html`
* Click `Open with Live Server`
